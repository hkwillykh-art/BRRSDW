# BRRS Professional / 商用級籃球裁判判例分析平台

版本規劃：v4.0 起。定位為「供籃球裁判、講師、審查委員及管理者共同使用的專業判例管理系統」。對外發表前應完成下列驗收；**此文件是規劃，不代表產品已符合商用要求**。

## 產品核心

- **影片工作室**：完整賽事匯入、關鍵影格、0.25–2 倍播放、逐格、前後畫面比較、畫線/圈選/箭頭、時間軸剪輯、片段匯出、多人檢視。
- **FIBA 判例庫**：球賽／節次／時間碼、賽事級別、位置、類別、規則條文版本、原始宣判、核定分析、影片證據、標籤與全文搜尋。
- **判例審查流程**：草稿 → 待審 → 專家意見 → 核准或退回 → 發布；區分「個人意見／多數投票／正式審核結論」，保留版本與審核紀錄。系統不能自己宣稱 FIBA 官方裁定。
- **團隊與教育訓練**：各級裁判／講師／審核者／群組管理員角色；私人群組，成員邀請與撤銷、教學影片測驗、學習報表。
- **隱私與商用治理**：明確賽事影片授權、個資告知、未成年人影像保護、資料留存及刪除政策、備份、災難復原、合規稽核。

## 目前基準（截至 2026-11-03）

現有 FastAPI + 原生前端，帳密登入、群組、基本影片上傳／播放、時間標記、三選一投票、留言、資料庫、R2/Supabase 的選配。**不是正式商用產品**：
- Render Free/暫存儲存不可作為商用持久化方案；
- 使用者無法自助找回密碼或驗證電子郵件；
- 附註畫線只有瀏覽器本機呈現，不會存成判例資料；沒有真正剪輯轉檔、工作佇列或多視角時間同步；
- 沒有審核流程、法律文件、資料匯出、異地備份、監控告警、負載及安全測試；
- 現有投票是帳號唯一，尚未防範同一個人註冊多個帳號；
- 雲端整合仍需真實憑證與持久化測試。

## 立即要處理的風險

1. **影片授權**：轉播、錄製及剪輯須有必要授權；YouTube 連結不等於任意可下載或公開再發布。
2. **安全帳號**：P0 的記憶體限速僅「單一進程」有效；公開商用前要接 WAF 或共用 Redis 限速，並加入電子郵件驗證/MFA。
3. **權限控管**：限時影片連結在有效期間內持有者可播放；正式版應評估經控管的媒體閘道及更短效時間。
4. **儲存與費用**：R2 的每月免費 10 GB-month 不是硬上限。大量下載、轉碼、存放會增加費用，不能宣稱無限免費。
5. **資料保存**：群組刪除目前會連帶清除判例、投票、留言及影片，應加入回收桶、刪除保留期與審計紀錄。
6. **治理**：區分使用者投票、講師解說、核定判例，不應無依據引用 FIBA 名稱表示官方背書。
