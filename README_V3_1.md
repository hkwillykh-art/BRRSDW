# BRRS V3.1 — 籃球裁判判例分析系統

這是一套**可自行架設的多人協作測試版**，不是已公開上線的網站。使用繁體中文介面，提供裁判帳號、私人群組、影片上傳與分析、判例搜尋、投票及留言功能。

## 啟動（Windows / macOS / Linux）

需要 Python 3.11 以上。

```bash
python -m pip install -r requirements.txt
python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

瀏覽器開啟 `http://127.0.0.1:8000`。在伺服器上架設時，請務必使用 HTTPS、正確設定防火牆及持久化儲存。

## 功能現況

- 帳號註冊、登入、登出；以雜湊方式保存密碼。
- 裁判群組及邀請碼；私人判例只有群組成員可讀取。
- 本機影片逐格（以 30 FPS 近似）、慢速播放、畫線、箭頭及圈選；影片畫線**不會燒錄或儲存至雲端**。
- 判例標題、FIBA 規則依據欄位、比賽與時間標記、搜尋。
- 上傳影片到伺服器，依帳號存取授權取得有效期 10 分鐘的影片連結；不代表已具備完整影片剪輯匯出。
- 每個登入帳號對**同一判例只能投一票**，不能更改；由 SQLite `PRIMARY KEY(case_id,user_id)` 與後端 HTTP 409 強制執行。
- 投票統計、裁判留言與群組資料庫。

## 測試

```bash
python -m pip install httpx
python -m unittest discover -s tests -v
```

測試範圍包括單一帳號防重複投票、不同帳號投票、無權限投票遭拒及投票統計。

## 免費雲端部署（僅供短期示範）

已附 `Dockerfile` 和 `render.yaml`，可在 Render 的適用免費方案部署；免費方案規則可能調整，需以供應商當時公告為準。部署仍需由擁有雲端帳號的人完成授權和發布。

**重要：這份預設設定使用本機 SQLite 和磁碟影片，免費主機重建或重新部署時資料可能消失。** 因此不能視為可長期使用的正式服務，**不要上傳機敏裁判資訊、個資或未經授權的賽事影片**。正式使用前需改成持久資料庫及影片儲存、備份、限制登入嘗試、身分驗證與權限測試，並取得賽事影片必要授權。

## 本版限制

- 不包含 AI 自動判例辨識、FIBA 官方規則資料全文、即時聊天室或真實影片裁切匯出。
- YouTube 僅支援連結儲存，不支援擷取及下載影片。
- 投票固定為「正確宣判／錯誤宣判／需要更多角度」三項；不是官方判例裁定。

## V3.1 額外檢查

- `/api/health` 回傳 HTTP 200 及資料庫連線狀態，供主機健康檢查。
- 投票選項由後端固定為「正確宣判／錯誤宣判／需要更多角度」；無效選項回傳 422。
- 相同登入帳號對同一個判例的投票仍由資料庫唯一鍵阻止，回傳 409。
- 預設最大影片上傳 25 MB，可用 `BRRS_MAX_UPLOAD_MB` 設定。

## 正式公開前必讀

Render 免費容器檔案系統通常不保證持久保存：**預設 SQLite 資料、帳號、投票和影片都有在重新部署後遺失的風險**。這是僅供不含真實個資的短期測試版，不是正式上線完成品。正式使用需要外部持久性資料庫、影片物件儲存、備份與權限稽核。免費額度、政策及適用性需在平台確認。請勿上傳未經授權影片。

部署簡表：將本目錄內容放入私人 GitHub 儲存庫 → Render 新建 Blueprint/Web Service，選擇該儲存庫與 `render.yaml` → 選用當時實際可用的免費方案 → 檢查 `/api/health` → 以虛構測試帳號測試；不要把測試版開放給正式裁判群組存放真實資料。
